Server administrator guide

Set up Pair Meet in minutes.

The guided setup wizard helps configure the channels and panels Pair Meet needs in your server.

Before you start

Invite Pair Meet to your server and make sure it has the permissions required to create channels, send messages, manage webhooks and configure the selected setup features. Administrator permission is the simplest way to avoid missing-permission errors, but you can also configure permissions individually.

Quick setup

01 · Invite the bot

Add Pair Meet to your Discord server.

02 · Run /setup

Start the guided setup wizard in a server text channel.

03 · Choose options

Select the Meet panel, chat category, report channel and other available setup options.

04 · Finish setup

Complete the wizard and check that the configured channels and panels were created correctly.

What can be configured?

  • Meet panel: the panel members use to start meeting people.
  • Statistics panel: a channel panel for Pair Meet activity statistics.
  • Chat category: the category used for temporary conversation channels.
  • Report channel: where moderators can receive user reports.
  • AutoMod sync: synchronization with Discord AutoMod features where supported.
  • Admin privacy: privacy-related setup options for server administrators.
If setup fails, check the bot's channel permissions and role position, then run /setup again. You can also visit the Support Server for help.
