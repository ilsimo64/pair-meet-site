Command reference

One bot. A lot of
ways to connect.

Browse the commands registered in the supplied Rust version of Pair Meet. “View bio” is a message context-menu action, not a slash command.

/setupServer admin

Configure Pair Meet. With no option, starts the guided setup wizard. Options: meetpanel, statspanel, chancategory, reportchannel, automod, adminprivacy.

Access: Manage Server
/setbioProfile

Set the biography shown to people you meet. Maximum 300 characters; leave empty to clear it.

Access: Everyone
View bioProfile

Message context menu. View a participant’s bio from a message inside your active Pair Meet chat.

Access: Everyone
/findMatching

Search for a chat with someone who shares an interest. Requires the interest option.

Access: Everyone
/endChat controls

Leave your current Pair Meet chat.

Access: Everyone
/skipChat controls

Leave your current chat and look for a new one.

Access: Everyone
/infoChat controls

Show information about your current Pair Meet chat.

Access: Everyone
/joinchatChat controls

Request to join an active Pair Meet chat using its up-to-4-digit code.

Access: Everyone
/incognitoPrivacy

Toggle anonymous Pair Meet mode.

Access: Everyone (server only)
/languageMatching

Choose the language you want to chat in (optional matching filter).

Access: Everyone
/friendsSocial

See the people you added as friends in Pair Meet.

Access: Everyone
/unfriendSocial

Remove someone from your friends.

Access: Everyone
/serversDiscovery

Get invite links for servers running Pair Meet. Optional name filter.

Access: Everyone
/privateServer admin

Toggle whether this server is hidden from /servers.

Access: Manage Server
/statusAccount

Show your Pair Meet status.

Access: Everyone
/unblockSafety

Unblock someone you previously blocked.

Access: Everyone
/blockwordSafety / moderation

Manage this server’s custom word filter: add, remove or list words.

Access: Manage Server
/meetbanSafety / moderation

Ban, unban or list users blocked from Pair Meet in this server.

Access: Manage Server
/deletemydataPrivacy

Delete everything Pair Meet stored about you.

Access: Everyone
/statsInformation

Show Pair Meet’s overall chat statistics.

Access: Everyone
/inviteInformation

Get the link to invite Pair Meet to another server.

Access: Everyone
/helpInformation

How to set up and use Pair Meet.

Access: Everyone
/supportmeInformation

Get the Pair Meet support server link.

Access: Everyone
/voteInformation

Get the link to vote for Pair Meet on top.gg.

Access: Everyone
/globalbanOwner tools

Ban, unban or list users banned from Pair Meet everywhere.

Access: Bot owner
/queuecheckOwner tools

See who is in the matching queue and why they are not matching.

Access: Bot owner
/refreshpanelsOwner tools

Push the latest Meet panel to every server at once.

Access: Bot owner
/setownerlogOwner tools

Use the current channel as the private log for reports.

Access: Bot owner
