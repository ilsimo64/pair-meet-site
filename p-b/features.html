What Pair Meet can do

Meet people. Start conversations.

Discover the tools that help Discord users connect across communities, find shared interests and manage their conversations.

🎲 Random matching

Meet someone new through the global matchmaking network and start a spontaneous conversation.

🎯 Interest matching

Use /find with a topic to look for people who share your interests. An optional language preference is available.

🌐 Cross-server chat

Talk with people from other Discord communities in a shared temporary chat.

🔢 Chat codes

Use a short code with /joinchat to request to join an active conversation.

🪪 Profiles and bios

Set a profile bio with /setbio. The “View bio” context menu lets participants view profiles where permitted.

🕶️ Incognito

Enable /incognito to hide profile details from other participants in supported profile views.

🔁 Message synchronization

Messages, replies, attachments, edits, deletions and reactions can be relayed between linked chat channels.

🛡️ Safety controls

Block users, report misconduct, use moderation tools and configure custom blocked words.

👥 Friends

Manage people you have met with /friends and /unfriend.

🔎 Server discovery

Find servers that use Pair Meet with /servers. Administrators can control listing visibility.

Feature availability may depend on server configuration, permissions and the current bot version.
