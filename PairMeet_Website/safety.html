Safety and control

Meet new people.
Keep control.

Pair Meet includes tools for participants and server administrators. Use them to manage unwanted interactions and configure moderation for your community.

🚫

Block and unblock

Block people you do not want to meet again. Use /unblock to reverse a block.

🕶️

Incognito

Toggle anonymous mode with /incognito. Profile viewing is suppressed for participants using incognito.

🚩

Report flow

Pair Meet has a report action and supports a configured report channel. The bot owner can configure a private report log.

🧹

Custom word filter

Server managers can add, remove and list words filtered in their server with /blockword.

🔗

Link and media policy

The chat bridge applies a link/media unlock policy based on chat age and message count. Tenor and Giphy GIFs are explicitly allowed.

🛡️

Server-level bans

Server managers can use /meetban to ban, unban or list users blocked from Pair Meet in that server.

Your data controls

The registered command /deletemydata is described in the bot as deleting everything Pair Meet stored about you. The source also includes a server setup option called Admin privacy. For details about exact retention periods, backups, third-party processing or legal jurisdiction, consult the operator before relying on assumptions: those details are not fully established by the command reference alone.

Server visibility

Servers can toggle whether they appear in the /servers discovery listing using /private.

If you encounter a problem, use the report action in the bot or contact the support server. Do not share sensitive personal information in public chat channels.
