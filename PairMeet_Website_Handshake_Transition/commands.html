Command reference

Pair Meet commands.

Use these commands in Discord to manage your profile, find conversations and control your Pair Meet experience.

Meet & chat

/find interest

Search for a conversation based on an interest.

/joinchat code

Request to join an active chat using its code.

/skip

Leave the current conversation and look for another match.

/end

End your current chat session.

/private

Manage whether your server appears in public server discovery.

/status

Check your current Pair Meet status.

Profile & social

/setbio

Set or clear your profile biography.

/incognito

Toggle incognito mode.

/friends

View your Pair Meet friends.

/unfriend

Remove someone from your friends list.

/blockword

Manage your custom blocked-word settings.

/language

Set your preferred language.

/unblock

Unblock a user.

/deletemydata

Request deletion of your stored user data.

Server setup & information

/setup

Open the guided server setup wizard.

/help

Show command help.

/invite

Get the bot invite link.

/info

View information about Pair Meet.

/stats

View Pair Meet statistics.

/servers

Discover servers using Pair Meet.

/vote

Open the bot voting option.

/supportme

View support options.

Some administrative and owner-only commands are intentionally not listed here. Discord may take a short time to refresh command updates.
