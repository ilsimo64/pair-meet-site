What Pair Meet can do

Everything to make
meeting easier.

These features are based on the Pair Meet Rust source provided for this website. Availability and behavior can depend on server configuration and Discord permissions.

🎯

Interest-based matching

Use /find with an interest to look for people who are into the same things. The /language command can add an optional language filter.

🌐

Cross-server conversations

Pair Meet relays messages between participants in a shared chat, even when they are in different Discord servers.

🔢

Join with a chat code

Invite someone into an active chat with /joinchat and its short code (up to four digits).

🪪

Profiles and bios

Set a short bio with /setbio. Use the “View bio” message context action to view a participant’s profile in your active chat.

🕶️

Incognito mode

Turn on /incognito to hide your profile from other participants. The bot’s profile-view flow explicitly respects this setting.

🔁

Live message sync

The Rust bridge mirrors message edits and deletions, replies, attachments and reactions across the linked chat.

🛡️

Chat safety

Pair Meet includes blocking and unblocking, user reports, server-level bans, a custom word filter and a link/media unlock policy.

⚙️

Server setup

Use /setup for the guided wizard or configure the Meet panel, stats panel, chat category, report channel, AutoMod sync and admin privacy individually.

👥

Friends

Add people you meet as friends, review your friends list with /friends and remove a friend with /unfriend.

🔎

Server discovery

Use /servers to find invite links for servers running Pair Meet. Server admins can hide their server from that listing with /private.

Note: the source confirms short chat codes of up to four digits. The maximum number of participants in a group chat is not specified here, so this website does not advertise a participant limit.

Invite Pair Meet and use /setup to get started.
