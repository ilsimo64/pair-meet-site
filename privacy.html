Privacy Policy

Last updated: November 16, 2026

This Privacy Policy explains how Pair Meet ("the Bot") collects, processes, stores, and protects information when you interact with it on Discord.

1. Data Stored Permanently

To provide matchmaking, safety features, and customization, the Bot stores the following data in its database:

  • Discord User IDs: Used to manage user preferences (such as Incognito mode), personal block lists, and Global Bans.
  • User Profiles & Interests: Optional profile biographies set via /setbio and interest tags submitted when searching via /find.
  • Server Configuration Data: Discord Server (Guild) IDs, designated category IDs, panel message/channel IDs, report channel IDs, privacy visibility settings (/private), and custom blocked-word lists configured by server administrators.
  • Safety & Report Records: Records of submitted abuse reports (reporter ID, reported user ID, timestamp, and associated report context) and Global Ban statuses.
  • Anonymous Aggregate Statistics: Total number of completed chats, cross-server chat counts, and session durations (stored without linking to individual User IDs).

2. Real-Time & Ephemeral Data (Not Permanently Stored)

Pair Meet requires Discord's Message Content, Presence, and Server Members intents solely to operate its core chat bridge:

  • Chat Messages, Attachments & Reactions: Processed in real time to relay messages via webhooks between private session channels, synchronize edits/deletions/reactions, and enforce safety filters. Messages are not logged to a permanent database.
  • Temporary Report Buffer: A short rolling buffer of the most recent messages in an active session is held temporarily in volatile memory (RAM) and automatically erased when the chat ends. If a participant clicks Report, this recent context may be forwarded to the relevant server moderators and Bot safety logs to investigate the violation.
  • Online Presence Status: Checked in real time solely to detect inactive participants in active chats or matchmaking queues (such as periodic activity confirmations) and is never recorded or stored.

3. Data Sharing & Visibility

We do not sell, rent, or trade user data to third parties. During a chat session, other participants can see your Discord display name, avatar, and server name unless you enable Incognito Mode, which replaces your name with "Stranger" and hides your avatar and server.

4. Data Retention & User Rights (Deletion Requests)

Users may clear their profile bio at any time using /setbio or manage blocked users using /meet unblock. Server administrators may remove server configurations or kick the Bot at any time.

To request the complete deletion of your stored data (excluding active Global Ban or abuse prevention records required for platform safety), please contact the developer via our Support Server.

5. Contact

If you have any questions regarding this Privacy Policy or how your data is handled, please reach out in our Support Server.
