Server setup

Up and running
step by step.

Pair Meet includes a guided setup wizard and individual setup options. You need the Manage Server permission to run server setup.

Quick start: run /setup in your server and follow the bot’s prompts. You do not need to run separate setup commands.
01

Invite the bot

Add Pair Meet to your Discord server using the invite button. Review the permissions Discord requests during installation.

02

Start the guided wizard

Run /setup with no option. The bot starts its guided setup flow.

03

Create the Meet panel

The wizard can configure the Meet panel where members can start meeting people.

04

Choose a chat category

Configure the category used for Pair Meet chat channels.

05

Set a report channel

Choose where server reports should be sent.

06

Configure optional modules

The setup options also include the stats panel, AutoMod synchronization and admin privacy.

07

Start meeting people

Use the Meet panel or run /find interest with an interest such as gaming, anime or music.

Need to configure one thing?

Use /setup and select one of these options: Meet panel, Stats panel, Chats category, Report channel, AutoMod or Admin privacy.
